# 硬币

宇航员Bob有一天来到火星上，他有收集硬币的习惯。于是他将火星上所有面值的硬币都收集起来了，一共有n种，每种只有一个：面值分别为a1,a2… an。 Bob在机场看到了一个特别喜欢的礼物，想买来送给朋友Alice，这个礼物的价格是X元。Bob很想知道为了买这个礼物他的哪些硬币是必须被使用的，即Bob必须放弃收集好的哪些硬币种类。飞机场不提供找零，只接受恰好X元。

**Input**

第一行包含两个正整数n和x。（1 <= n <= 200, 1 <= x <= 10000)
第二行从小到大为n个正整数a1, a2, a3 … an （1 <= ai <= 10000)

**Output**

第一行是一个整数，即有多少种硬币是必须被使用的。
第二行是这些必须使用的硬币的面值（从小到大排列）。

**Sample**

| Input            | Output   |
| ---------------- | -------- |
| 5 18<br>1 2 3 5 10| 2<br>5 10 |

**Hint**

输入数据将保证给定面值的硬币中至少有一种组合能恰好能够支付X元。
如果不存在必须被使用的硬币，则第一行输出0，第二行输出空行。

#include<iostream>
#include<algorithm>
#include<cstring>
#pragma GCC optimize(3)
using namespace std;
int n,x,a[2100],k=0,cnt=0,p[2100],q[2100];
//	int v[1000][1000];
int v[10000];
int check(int t){

	memset(v,0,sizeof(v));
	int f=1;
	for(int i=1;i<=n;i++){
		if(i==t)
			continue;
		else
			q[f++]=a[i];
	}
	f--;

	v[0]=1;
		for(int i=1;i<=f;i++){
			for(int j=x;j>=q[i];j--){
			v[j]=v[j]+v[j-q[i]];
                /*必须从x开始递减*/
			}
		}
	
	
		if(v[x]==0)
			return 0;
		else
			return 1;

// 如果从0开始，就要用二维数组
//		}
//	}

//	if(v[f][x]==0)
//		return 0;
//	else

}



int main(){
	
	cin>>n>>x;
	
	for(int i=1;i<=n;i++)
		cin>>a[i];
	for(int i=1;i<=n;i++){
		if(check(i)==0){
			cnt++;

		}
		
	}
	
	cout<<cnt<<endl;

		cout<<p[i]<<" ";
	}
}
