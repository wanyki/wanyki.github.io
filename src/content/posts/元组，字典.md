## 元组

### index查询

```python
my_tuple=('et',77,99.9)
print(my_tuple.index(99.9))
#元组不可修改，index查询位置
```

## 字典

```python
info = {'name':'班长', 'id':100, 'sex':'f', 'address':'地球亚洲中国北京'}
print(info['name'])
#print:班长
print(info['x'])
#print:抛出异常
print(info.get('name'))
#print:班长
print(info.get('t'))
#print:None
print(info.get('t','pp'))
#pint:pp，如果get没有找到 默认输出None，如果有第二变量输出第二变量
```

## 字典的修改添加

```python
info = {'name':'班长', 'id':100, 'sex':'f', 'address':'地球亚洲中国北京'}
s=input("请输入要修改的id:")
info['id'] = int(s)
#print('修改之后的id为:%d'%info['id'])
info['tt'] = 'sss'
#如果没有:'tt'键则自动新增一个
print(info)
```

## 删除元素

```python
info = {'name':'班长', 'id':100, 'sex':'f', 'address':'地球亚洲中国北京'}
del info['name'] #删除name
del info #删除整个字典
info.clear()#清空整个字典
```
