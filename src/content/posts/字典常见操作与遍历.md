#### len()

测量字典中，键值对的个数

```python
dict = {'name':'jwq','sex':'man','number':'123456'}
print(len(dict))
```

#### keys&&values

返回一个包含字典所有KEY的列表

```python
dict = {'name':'jwq','sex':'man','number':'123456'}
print(dict.keys())
#dict_keys(['name', 'sex', 'number'])
print(dict.values())
dict_values(['jwq', 'man', '123456'])
```

#### items

返回一个包含所有（键，值）元祖的列表

```python
dict = {'name':'jwq','sex':'man','number':'123456'}
print(dict.items())
#dict_items([('name', 'jwq'), ('sex', 'man'), ('number', '123456')])
```

#### 遍历(带下标)

```python
dict = {'name':'jwq','sex':"man",'number':'123456'}
for i , chr in enumerate(dict.items()):
    print(i,chr)
```
